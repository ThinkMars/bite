Bite

## Introduction

Bite is a web build tool that build your web application. It's inspired by [**vite**](https://vite.dev/) and powered by [**Bun**](https://bun.sh/).

## Usage

1. Make sure you have installed **Bun** on your machine.
2. Run `bite dev` to start the development server.
3. Run `bite build` to build your application.
